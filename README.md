# Enterprise Process Intelligence & Lean Six Sigma

A DMAIC-based process-analytics case study focused on reducing enterprise proposal cycle time through process mapping, baseline measurement, segmentation, statistical analysis, root-cause investigation, and control planning.

## Business context
XYZtech is a $60B multinational operating in roughly 100 countries with more than 150,000 employees and contractors. After an 18% revenue decline, leadership challenged the supply-chain organization to reduce operational cycle time by 15%. The selected process was sales-proposal creation, where handoffs between sellers, bid support, product design, pricing, brand management, and proposal management created delay and rework.

## Portfolio story
**Business problem → VOC/CTQ → process map → baseline KPIs → DPMO/sigma → segmentation → root causes → improvement recommendations → control plan**

## Core analytical capabilities
- Lean Six Sigma / DMAIC
- Voice of Customer and Kano thinking
- Critical-to-Quality metrics
- SIPOC and swimlane mapping
- cycle-time distributions
- SLA/defect analysis
- DPMO and sigma-level reasoning
- Pareto analysis
- segmentation by geography, brand, seller, BSS and bid size
- statistical process control
- process capability
- factorial DOE / ANOVA
- residual/model-adequacy analysis
- operational recommendations

## Evidence boundary
The XYZtech case is an academic case study. Portfolio materials preserve the course framing and analyses; they do not represent work performed for the fictional company.

## Professional connection
The project complements professional healthcare and supply-chain analytics experience by showing a formal process-improvement framework for turning operational data into measurable interventions, controls, and stakeholder recommendations.
