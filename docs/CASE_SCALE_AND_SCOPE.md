# Case Scale and Scope

The academic XYZtech case is framed as a multinational technology company with:
- approximately $60B annual revenue,
- operations in more than 100 countries,
- more than 150,000 employees/contractors,
- an 18% two-year revenue decline,
- a 15% proposal-cycle-time reduction mandate.

The Define/Charter artifacts state that the historical ERP dataset contains **75,000 proposal transactions** with timestamps, geography, seller, product brand, Bid Support Specialist, bid value and stakeholder feedback.

This is academic case data, not professional employer data.
