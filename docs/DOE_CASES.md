# DOE / Factorial Analysis Evidence

## Cutting-tool life
The submitted analysis concluded that metal hardness, cutting angle, and the cutting-speed × cutting-angle interaction significantly affected tool life, with reported p-values .009, .020 and .001. Low cutting speed + high cutting angle produced consistently strong results; the highest observed combination cited was 552.5 at high hardness.

## Soft-drink 2^4 factorial
The overall factorial model was reported significant (p=.009). Sweetener type was the only significant main effect (p<.001), with significant AB, ABC and ABD interactions. Reported R² was 76.49%, while predicted R² was only 5.97%, an important warning about predictive generalization. The highest observed average taste score was 196.5 for the cited treatment combination.

## Surface roughness 2^4
The submitted analysis identified B (cutting-fluid viscosity), A (tool angle), C (feed rate), and AB as dominant effects using the normal probability/Pareto evidence and sparsity-of-effects principle. Residual diagnostics were interpreted as showing no substantial model inadequacy.
